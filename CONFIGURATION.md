# Конфигурация проекта

Этот файл описывает все переменные окружения и константы, которые можно настроить в проекте.

## Переменные окружения (.env)

Эти переменные должны быть указаны в файле `.env` в корне проекта.

### Основные настройки
| Переменная | Описание | Значение по умолчанию | Обязательно |
|------------|----------|-----------------------|-------------|
| `MAXAPI_TOKEN` | Токен бота от MAX API. | - | Да |
| `ADMIN_ID` | Telegram ID администратора (оператора поддержки). | - | Нет (но рекомендуется) |

### Настройки вебхука
| Переменная | Описание | Значение по умолчанию |
|------------|----------|-----------------------|
| `WEBHOOK_MODE` | Режим работы вебхука: `xtunnel` или `direct`. | `xtunnel` |
| `XTUNNEL_URL` | Публичный URL туннеля (если используется xtunnel). | - |
| `DIRECT_WEBHOOK_URL` | Прямой публичный URL вебхука (если `WEBHOOK_MODE=direct`). | - |
| `WEBHOOK_PORT` | Локальный порт для запуска веб-сервера. | `8083` |

### Внешняя система МИС
| Переменная | Описание | Значение по умолчанию |
|------------|----------|-----------------------|
| `MIS_API_URL` | Базовый URL API МИС для синхронизации записей. | - |

### База данных (PostgreSQL)
| Переменная | Описание | Значение по умолчанию |
|------------|----------|-----------------------|
| `DB_NAME` | Имя базы данных. | - |
| `DB_USER` | Пользователь базы данных. | - |
| `DB_PASSWORD` | Пароль пользователя базы данных. | - |
| `DB_HOST` | Хост базы данных. | `localhost` |
| `DB_PORT` | Порт базы данных. | `5432` |

## Ключевые константы в коде

Некоторые настройки заданы жестко в коде, но их можно изменить при необходимости.

### В `bot_config.py`
- **MAX_API_BASE_URL**: `https://platform-api.max.ru` - базовый URL API платформы.
- **Ссылки**:
    - `GOSUSLUGI_APPOINTMENT_URL`: Ссылка на запись к врачу (Госуслуги).
    - `GOSUSLUGI_MEDICAL_EXAM_URL`: Ссылка на диспансеризацию.
    - `GOSUSLUGI_DOCTOR_HOME_URL`: Ссылка на вызов врача на дом.
    - `GOSUSLUGI_ATTACH_TO_POLYCLINIC_URL`: Ссылка на прикрепление к поликлинике.
    - `CONTACT_CENTER_URL`: Ссылка на ЕКЦ.
    - `MAP_OF_MEDICAL_INSTITUTIONS_URL`: Ссылка на карту медучреждений.

### В `support_handler.py`
- **INACTIVITY_TIMEOUT**: `7200` (2 часа) - время бездействия, после которого чат поддержки автоматически закрывается.
- **LOG_RETENTION_DAYS**: `30` - количество дней хранения логов чатов поддержки.

### В `sync_appointments/fetcher.py`
- **max_retries**: `10` - количество попыток повторного запроса к МИС при ошибке.
- **retry_delay**: `600` (10 минут) - задержка между попытками запроса.

### В `logging_config.py`
- **Настройки ротации логов**: Хранение 30 последних файлов логов (`backupCount=30`), ротация каждый день в полночь.
- **Маскирование**: Включено маскирование телефонов и ФИО в логах.

### Настройки времени и расписания

#### Синхронизация (в `sync_appointments/scheduler.py`)
- **Ежедневная синхронизация**: Запускается каждый день в **08:00** (по Москве).
- **Еженедельная очистка**: Запускается каждое воскресенье в **03:00** (по Москве).
- **Проверка состояния**: Запускается каждый час.

#### Уведомления (в `sync_appointments/utils.py`)
- **Окно отправки уведомлений**: С **08:00 до 22:00**. В ночное время (с 22:00 до 08:00) уведомления не отправляются, чтобы не беспокоить пользователей.
